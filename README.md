# ESP-32-Car-ENG177

ENG 177 project repository for the ESP-32 Car.

## Build / Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/MikewangBJ101ID/ESP-32-Car-ENG177.git
   cd ESP-32-Car-ENG177
   ```
2. Open this project in your ESP32 development environment (Arduino IDE or PlatformIO).
3. Install required ESP32 board packages and libraries in your environment.
4. Build and upload to your ESP32 board.
